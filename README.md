# SL Zovi — Android aplikacija

Omotač (WebView) oko web aplikacije https://call.1379000.xyz sa pravim obaveštenjima o pozivima (Firebase Cloud Messaging),
zvonjenjem preko zaključanog ekrana i servisom koji drži poziv aktivnim u pozadini.

APK se pravi automatski (GitHub Actions) na svaki push u `main`. Najnovija verzija:
`https://github.com/belisexhelper/sl-zovi/releases/latest/download/SL-Zovi.apk`

Firebase se podešava u web aplikaciji: Admin → Server → „Android obaveštenja (Firebase)". Nikakvi ključevi se ne čuvaju u ovom repou.
